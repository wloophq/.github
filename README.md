# wloophq/.github

Default community health files for every repository in the wloophq organization: the contributing guide, the security policy, and the issue and pull request templates. A repository with its own copy of a file uses its own.

`profile/README.md` is the organization's public profile.

`scripts/setup-repo.sh <repo> [required-check]...` applies the organization's repository defaults to a new repository (squash merge only, branches deleted on merge, and a ruleset protecting the default branch). Security features come from the organization's default code security configuration, which applies to new public repositories on its own.
